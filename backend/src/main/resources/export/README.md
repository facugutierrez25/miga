# Marca en las exportaciones

`miga-wordmark.png` reproduce el componente oficial `frontend/src/components/Brand.tsx`
y las reglas `.brand`, `.brand-i` y `.brand-i::after` de `frontend/src/index.css`.
Se renderizó en Chromium a 4×, con Bricolage Grotesque 700 a 26 px,
el verde bosque `#2F6336` y el punto amarillo `#F6C344`, sobre fondo transparente.

PDF y Excel usan esta misma imagen, conservando su proporción. No se usa el ícono
de instalación ni se reconstruye el nombre con una fuente de texto del documento.

Onest.ttf es la fuente embebida para el contenido de los PDF; su licencia está en OFL-Onest.txt.
